## Latest Note

Switchboard is useful when it presents task ledgers, scope, freshness, branch metadata, and handoff evidence together. It becomes misleading when agent usage notes look like human-facing prompt controls or when local git history is treated as the main activity map.

## Useful

- Switchboard task ledgers and snapshots expose stale planning assumptions that would otherwise be hidden in chat.
- Branch metadata helps orient the worktree when it is clearly marked as metadata only.

## Confusing

- A former prompt-control pattern made the product look like it was collecting human UI notes instead of agent-authored usage evidence.
- A local git activity grid made commit history look like the primary dashboard truth.

## Tedious

- Re-validating raw notes, task ledgers, repo metadata, and UI state takes many steps when the source map is not explicit.

## Context Helped

- Raw May 22 notes and the Brick 8A prompt corrected the product frame before accepting the dashboard sweep.

## Snapshot Sync Clarity

- Snapshot/verify is clear as an explicit command.
- Future watcher automation should stay parked until collection semantics are stable.
